## Observations

- **The stable core is the instruction stack, not the tool surface.** Between two sessions hours
  apart the system prompt, all four `CLAUDE.md`-class files and the memory index did not move by a
  byte, while MCP servers dropped from 8 to 2, agent types from 13 to 12 and skills by roughly nine.
  Anything a workflow depends on from the tool surface has to be checked at run time, not assumed.
- **Guidance can outlive its tools.** §1.15 documents the full Claude in Chrome protocol and §10 still
  offers the `claude-in-chrome` skill, yet not one `mcp__claude-in-chrome__*` tool exists here. The
  `playwright-extension` server is the only browser stack actually reachable.
- **Turning Ultracode off removes a contradiction rather than a capability.** With §11 gone, the
  system prompt, the `Workflow` opt-in gate and the repo's own "do not use subagents for a small edit"
  rule finally agree: no multi-agent orchestration unless the user asks for it.
- **The MCP-resource tools are not free-standing.** `ListMcpResourcesTool` / `ReadMcpResourceTool` /
  `ReadMcpResourceDirTool` disappeared along with the servers, so their presence is a signal about
  configuration, not about the harness version.
- **`docs/context/` is untracked in both captures.** The first snapshot exists only in the working
  tree; neither file is in git history yet.
