Паспорт-чекер

Виджет проверяет заранее настроенный статус паспорта через серверный RPC. Без полей ввода, одно действие — «Проверить». Ниже: плитка в тирах tiny и standard для всех состояний, модалка восстановления сессии браузера с noVNC, и спека. Собрано на существующих токенах myboard — новый визуальный язык не вводится.

Hanken Grotesk — интерфейс и заголовки. JetBrains Mono — метки, числа, статус-код, таймер и SSH-команда.
Паттерн retryable-ошибки
Один блок на --destructive-soft с бордюром hue 27: иконка-alert (17–18px) + жирная строка сообщения (600/14) + короткая подсказка «Попробуйте ещё раз». Под ним — единственная кнопка «Повторить» (secondary, с иконкой refresh). Меняется только текст сообщения; вёрстка, цвета и кнопка идентичны для всех четырёх строк.
Баннер sessionRequired
Единственный «внимание»-акцент вне палитры статусов: тёплый янтарь hue 70–80 (та же цветность, что у success), чтобы отличаться от ошибки. Треугольник-warning + «Требуется вход в браузер». Действие — «Открыть восстановление» в --accent (primary), т.к. это единственный путь дальше. В tiny вся плитка окрашивается в янтарный фон, текст сворачивается в 2 строки, кнопка «Открыть».
Модалка · размеры, адаптив, noVNC
Размеры и адаптив
Desktop: диалог 920px шириной, до min(620px, 90vh), центр по портал-оверлею, backdrop rgba(20,22,40,.45) + blur 2px. Радиус 18, shadow-lg.
≤ 960px: ширина 92vw. ≤ 640px: полноэкранный sheet (радиус 0, тело растягивается, футер прилипает к низу). Шапка и футер фиксированы, тело скроллится.
Кадрирование noVNC
Канвас 1280×720 в рамке aspect-ratio 16/9 на фоне #16171d. Масштаб contain: вписывается по ширине, по высоте — letterbox тёмными полями. Углы 12px, overflow hidden. Бейдж LIVE + разрешение сверху-слева, подпись масштаба снизу-справа.
Фокус и клавиатура
При открытии фокус уходит на диалог, focus-trap держит Tab внутри (шапка → тело → SSH → футер → закрыть). Esc закрывает (эквивалент «Закрыть»); клик по backdrop — тоже. При закрытии фокус возвращается на кнопку «Открыть восстановление» в плитке. Когда канвас в фокусе, стрелки/ввод уходят в noVNC, Esc перехватывается модалкой.
